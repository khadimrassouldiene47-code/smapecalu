Intégration Supabase Cloud

Votre projet Supabase est déjà configuré dans js/config.js. Pour activer la synchronisation de base de données en direct sur Supabase, exécutez simplement ce script SQL dans votre console Supabase :

-- SMAPEC: Table des produits et politiques de sécurité CREATE TABLE IF NOT EXISTS public.products ( id TEXT PRIMARY KEY, name TEXT NOT NULL, category TEXT NOT NULL, price NUMERIC DEFAULT 0, height NUMERIC DEFAULT 0, width NUMERIC DEFAULT 0, thickness NUMERIC DEFAULT 0, material TEXT, image TEXT, description TEXT, badge TEXT, created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() ); -- Activation de la sécurité au niveau des lignes ALTER TABLE public.products ENABLE ROW LEVEL SECURITY; -- Autoriser la lecture publique pour le catalogue CREATE POLICY "Public Read Products" ON public.products FOR SELECT USING (true); -- Autoriser l'écriture pour les opérations CREATE POLICY "Allow Full Access" ON public.products FOR ALL USING (true);

Statut actuel :

Le système utilise actuellement un stockage hybride : dès que la table Supabase est exécutée, le catalogue se synchronisera automatiquement sans aucune modification de code.
