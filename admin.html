Configuration & Synchronisation

Votre système utilise un stockage hybride LocalStorage + Supabase Cloud. Pour activer la synchronisation en temps réel, exécutez le script SQL dans votre console Supabase.

Statut : Système opérationnel

Le catalogue se synchronise automatiquement dès que la table Supabase est activée.

-- SMAPEC: Table produits CREATE TABLE IF NOT EXISTS public.products ( id TEXT PRIMARY KEY, name TEXT NOT NULL, category TEXT NOT NULL, price NUMERIC DEFAULT 0, height NUMERIC DEFAULT 0, width NUMERIC DEFAULT 0, thickness NUMERIC DEFAULT 0, material TEXT, image TEXT, description TEXT, badge TEXT, created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() ); ALTER TABLE public.products ENABLE ROW LEVEL SECURITY; CREATE POLICY "Public Read" ON public.products FOR SELECT USING (true); CREATE POLICY "Allow Write" ON public.products FOR ALL USING (true);
